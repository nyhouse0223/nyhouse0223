### About

- **직접 겪은 불편에서 시작합니다.** 학생회에서 기업 제휴를 맡으며 느낀 비효율을 창업 프로젝트로 만들었습니다.
- **확인한 것만 말합니다.** 데이터를 직접 열어보고 검증하며, 없는 값은 지어내지 않고 '미제공'으로 표시합니다.
- **작게 쪼개서 직접 해봅니다.** 모르는 기술은 묻고, 작은 단위로 실행해보며 이해합니다.
- **기술과 기획 사이를 잇습니다.** 기술 결과를 이해해 팀과 사용자가 알아듣는 말로 정리합니다.
